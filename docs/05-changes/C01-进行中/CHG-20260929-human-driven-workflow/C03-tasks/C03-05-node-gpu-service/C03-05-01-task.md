# C03-05｜退出自托管 GPU，保留 Node.js 客户端

> 2026-09-29 用户已明确确认能力退出，沿用当前 Agent 串行实施；不创建 Worker/worktree。

## 目标与边界

删除仓库内自托管 GPU/Laya 推理服务及专属辅助、协议测试、Python CI/依赖和部署说明。仅保留 Node.js HTTP/MCP 客户端连接外部兼容服务，不通过 Node 包装 Python，不移植或伪造 Node GPU 引擎。历史 Git/Change/调查和兼容 fixture、用户环境保持不变。

## 输入与总体方向

用户明确回复“可以移除自托管GPU服务，只保留nodejs”。现有 Node 客户端独立实现端点配置、认证、请求/响应验证、超时、缓存和 fallback；服务端模型/硬件/推理由外部提供方负责。清理分发资产与当前指导，保留客户端现有公开工具和安全/协议回归。

## 验收与验证

- 第一方 Python 源码为零，无 GPU 专属 Python CI/依赖或部署入口。
- 消费包和受管 runtime 不携带 GPU 服务资产，Node 客户端仍可实际使用四个公开 MCP 工具。
- 客户端协议与安全回归通过，必要核心全量验证和文档检查如实记录；不声称验证了外部模型/硬件。
- 最终交付由用户确认，能力删除授权不等于归档或发布许可。
