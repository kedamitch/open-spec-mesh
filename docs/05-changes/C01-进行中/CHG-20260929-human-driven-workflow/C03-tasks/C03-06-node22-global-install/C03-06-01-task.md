# Node 22、全局安装与旧脚本清理

## 目标和范围

支持 Node >=22.0.0 和真实 npm -g 分发；升级本机 ~/.codex 受管资产，删除全部旧 SDD Python/scripts/cache，保全用户内容。解除 private 限制不等于已发布 registry。

## 宏观方案

统一运行版本与锁元数据；检查已安装脚本模块启动；消费真实 tarball/global bin；在安装事务中应用受管旧资产退役；先隔离验证再实际升级。

## 验收和执行

Node 22.0.0 与当前 Node 24 核心检查通过；最低版本的全局命令、已安装 Skill/MCP 均能工作；四个点名路径及受管旧脚本/cache 不存在；未受管 Python 保留。按用户授权当前 Agent 串行实现，无新 Worker/worktree。外部宿主全量扩展与发布不混同为本轮核心结果。
