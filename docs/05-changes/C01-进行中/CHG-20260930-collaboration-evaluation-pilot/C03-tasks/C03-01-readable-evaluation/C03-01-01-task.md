# C03-01 可读评估

## 可执行目标与范围

实现--format json/md与--fail-on-incomplete；默认行为保留，三态报告醒目。验收：默认JSON可解析；md带状态/unknown/人工未验证；strict incomplete=3而fail=1，usage=2；--list两种格式；输入内容不泄漏且只读。公共约定引用[C02](../../C02-design.md)，不另抄状态表。

## 输入、方向和交付

输入为现有evaluation模块、规范化fixture与当前CLI parser；无其他Task依赖。先最小验证旧incomplete=0，再增加renderer与参数处理；测试覆盖完整、失败、partial/opaque及无自动项、安全/读写和包消费。路径仅定位，不冻结实现。输出源码/测试/使用说明及实际Delivery；不扩展自动调度、token采集、真实模型评测或全局安装。

## 验证与调整

Main执行定向评估回归，完成后一次core作为集成/安全/文档/消费验证；重复检查仅因代码或证据变化，原因记录Delivery。内部修复就地完成，只有实质目标、安全/公共约定变化请求用户决定。
