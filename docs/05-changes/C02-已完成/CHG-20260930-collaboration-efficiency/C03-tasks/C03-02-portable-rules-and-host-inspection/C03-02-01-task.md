# C03-02｜通用规则安装与宿主核验

## 目标与范围

覆盖已确认设计 B4–B5、C4。安装来源隔离、共享副本单源维护、按需只读宿主核验。不得覆盖用户规则、读取秘密值或声称已知当前活动会话。

## 输入与依赖

依赖：C03-01。共享方案见 [Design](../../C02-design.md)，不重复产品背景；缺少的实时模型或活动会话证据明确未知。

## 交付输出

通用规则单源、安装和适配回归、文件配置核验入口与指引。

## 任务级设计

### 总体实现方向

在已有安装/适配边界使用统一通用来源，保留本仓库专用规则与已有副本路径；核验仅导出非敏感字段和证据局限。 文件、函数与局部实现由当前执行者决定。

## 验收与验证方向

跨宿主安装不得混入项目发布信息，升级保全自定义内容；只读核验不外泄凭据，执行安装与宿主定向测试。 本任务定向验证由 Main 完成，跨任务集成由 Main 在 C03-04 完成；仅证据失效或不足时重复验证。
