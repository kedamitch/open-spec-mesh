# 执行计划

## 范围与交付

遵循 [已确认设计](../C02-design.md)，完整保留文档结构。当前 Agent 据用户“SDD 模式直接执行”授权编制计划并串行实施；此计划未另行声称获得逐项人工批准。

## 执行方式与集成

四个宏观任务由 Main 在当前工作区串行完成，不启动 Worker、不新建 worktree。先收敛共享协作语义，再接入安装与观测，最后集成验证和交付；每项任务就近做定向测试。共享输入为已确认优化表及现有真实实现，未验证的活动会话配置保持未知。

## 整体验证方向

检验 docs/01–09 和现有工件导航完整、模板创建兼容、通用规则安装隔离、用户配置保全、无 Graph 指标诚实、会话用量去重、宿主核验秘密不外泄。适用定向验证与 npm run validate:core；native/full 按实际宿主能力执行并如实记录，不执行真实多模型成本评测。
