# C03-01｜运行时接线

## 目标与范围

段 A：让 preset-sdd 的每条插件配置都能被宿主真实消费。范围是 `dsh/cordis.patch.yml`（persona 内联与 persona 正文修订）、`dsh/gatekeeper.mjs`（角色路由 section、pre-step 门控、等级判定、压缩重置），并删除 `dsh/prompts/sdd-persona.md`。对应设计 P0-1、P0-2 与三条 P1，见 [根因与设计](../../C02-design.md)。

## 输入与依赖

- 宿主契约（只读）：persona 的 `prefix: string`（`dsh-persona/lib/types/index.d.ts:30`、`dsh-persona/lib/index.js:39`）、patch 只锚定 `name`（`dsh-app-boot/lib/index.js:3969-3977`）、ToolRuntime 方法集合（`dsh-tools/lib/types/index.d.ts:610`）、`assistant/message` 事件（`dsh-session/lib/types/types.d.ts:331-338`）、压缩生命周期（`dsh-compaction-basic/lib/index.js:469`、`:484`、`:495`）。
- 模型路由事实来自 `lib/installation/models-config.js`（段 B 完成后由单一事实源提供；本段先注册 section，渲染逻辑不重复实现）。
- 无前置任务；B、C 依赖本段结论。

## 交付输出

修改后的预设与插件；persona 死文件删除；覆盖本段行为的定向单测（`tests/node/dsh/gatekeeper.test.js`）。

## 任务级设计

### 总体实现方向

把"插件自造一层"改成"插件只提供事实、行为交给宿主"：路由表作为 system prompt section 渲染，派发走原生 `subagent`；门控与裁剪落在 `agent/pre-step`；等级从 `session.surface.nodes` + `session.eventAt(seq)` 读 `assistant/message` 文本。函数拆分、命名与内部组织由执行者决定，不在此处逐文件规定。

## 验收与验证方向

- `node --test tests/node/dsh/gatekeeper.test.js` 通过（fake ctx 层面：section 注册、pre-step 裁剪与保留字段、定级匹配、压缩重置）。
- `dsh --profile web --patch ./dsh/cordis.patch.yml --dump-config` 退出码 0，且组合结果包含预设名、persona 散文正文与 gatekeeper 条目。
- 不声称上述结果等于"真实会话中 hook 已生效"。
