# C03-02｜CLI 命令与表格交互呈现

## 目标与范围 (Goal & Boundary)

- **交付目标**：在 `lib/cli/models.js` 中接入 `doctor` 与 `check` 子命令，格式化输出对齐表格、问题列表及修复建议，并正确返回退出码。
- **模块边界**：`lib/cli/models.js`、`tests/node/cli/models.test.js`。
- **不做事项**：不引入额外的三方依赖（如 cli-table3 等）。

## 输入与依赖 (Inputs & Dependencies)

- **依赖前置任务**：C03-01（调用 `diagnoseModelsConfig`）。
- **架构方案引用**：[C02 Design](../../C02-design.md) 中的表格排版与建议样式规范。

## 交付输出 (Deliverables)

- `lib/cli/models.js` 扩展支持 `osm models doctor` 与 `osm models check`。
- 实现纯原生字符对齐排版的诊断表格渲染。
- 输出问题提示与可直接复制粘贴的修复命令。
- 根据 `report.exitCode` 返回 0 或 1。
- 编写 CLI 层面的单测，验证表格输出、建议内容及命令退出码。

## 验收与验证 (Acceptance Commands)

- **定向执行命令**：
  ```bash
  node --test tests/node/cli/models.test.js
  node bin/osm.js models doctor
  node bin/osm.js models check
  ```
