# C03-02｜CLI 导出还原子命令接入与命令测试

## 目标与范围 (Goal & Boundary)

- **交付目标**：在 `lib/cli/models.js` 中接入 `osm models export [filepath]` 与 `osm models import <filepath> [--force]` 子命令，提供参数解析、覆盖保护拦截展示、错误提示与退出码处理，更新用法提示，并在 `tests/node/dsh/models-cli.test.js` 中完成端到端命令行集成测试。
- **模块边界**：`lib/cli/models.js`、`tests/node/dsh/models-cli.test.js`。
- **不做事项**：不改写 `models-config.js` 底层文件读写逻辑（调用工单 1 提供的标准内核接口）。

## 输入与依赖 (Inputs & Dependencies)

- **依赖前置任务**：依赖 C03-01 提供的 `exportModelsConfig` 与 `importModelsConfig` 方法签名。
- **架构方案引用**：[C02 Design](../../C02-design.md) 中 CLI 交互与时序图设计。
- **外部契约与输入**：`runModelsCommand(argv, streams, homeDir)`。

## 详细任务与交付要求 (Deliverables)

1. **`lib/cli/models.js` 扩展分发**：
   - 增加 `export` 分支：
     - 支持读取可选参数 `argv[1]` 作为目标路径；
     - 调用 `exportModelsConfig(targetPath, homeDir)`；
     - 成功时 stdout 输出 `已成功导出模型配置至: ${result.targetPath}\n`，返回 0；若失败输出 stderr 并返回 1。
   - 增加 `import` 分支：
     - 解析参数：提取第一个非 flag 参数作为 `filepath`；解析 `--force` 与 `-f` 选项；
     - 若未传 `filepath`，向 stderr 打印 `错误: 必须指定导入文件的路径。\n用法: osm models import <filepath> [--force]\n`，返回 1；
     - 调用 `importModelsConfig(filepath, { force }, homeDir)`；
     - 若返回 `blocked: true`（被覆盖保护拦截），向 stderr 打印 `错误: 目标模型配置文件已存在 (~/.dsh/osm-models.json)。若需覆盖，请添加 --force 参数。\n`，返回 1；
     - 若其他失败（源文件不存在或校验失败），向 stderr 打印 `错误: ${result.reason}\n`，返回 1；
     - 若成功，向 stdout 打印 `成功从 ${filepath} 还原模型配置至: ${result.targetPath}\n`，返回 0。
   - 更新未知子命令的错误用法提示，增加 `export [filepath]` 与 `import <filepath> [--force]`。
2. **命令行集成测试（`tests/node/dsh/models-cli.test.js`）**：
   - `osm models export` 缺省目标路径导出（当前目录下 `osm-models-backup.json`）及自定义路径导出；
   - `osm models import` 缺少 filepath 报错；
   - `osm models import` 源文件损坏或不存在时报错；
   - `osm models import` 目标已存在且无 `--force` 拦截测试；
   - `osm models import` 目标已存在且带 `--force` 成功覆写测试；
   - 未知子命令错误提示包含 `export` 与 `import`。
