# Laya 可复用语义判断

日期：2026-09-24。

## 交付

- 固定 execution-mode@1 / delegation@1 模板；通用模板扩展，不逐次生成契约，不强制每轮调用。
- 命名批量 MCP、单条兼容、显式真批处理服务；未配置合批时回退，不暗中串行。
- --without-laya / --with-laya；工具、适配技能、提示和检查同步启停，保留原 typesafe-ai 和自定义配置。
- 进程缓存、限定模型版本、失败熔断、精简结果和可选无正文指标。
- Simple 按需调查权限与 Laya 开关分离；原有审批、固定模型配置及叶子角色边界保留。

## 验证范围

单元测试覆盖启停往返、禁用无请求、旧单条协议、真批处理调用、返回对齐、模板扩展、缓存失效、权限候选过滤、密钥脱敏和安装回滚。集成 CI 使用真实 MCP SDK 配合本地模拟 HTTP 服务。

未将模拟返回当作实际路由质量；未验证用户 GPU、TileLang 性能或真实节省。GPU 主机需单独部署批量入口，旧服务仍可处理单条请求。
