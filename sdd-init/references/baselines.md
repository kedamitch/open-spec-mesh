# 文档基线

沿用 docs/01–09 分类；Current Truth 写真实产品、架构和运维，Change 写增量需求、Design 写整体方案，Task 写宏观业务结果，Delivery 写实际结果。目录 index 只作导航。

新 Change 按阶段产生 C01-change.md、C02-design.md 和 C03-tasks/；任务计划是 C03-task-plan.md，各编号 Task 目录实际完成时再增加 Delivery。未来工件未创建不是错误，新流程不产生执行 Graph。历史 Graph/记录只读保留。

详见 [文档契约](document-contract.md) 与 [人工工具指南](runtime-guide.md)。
