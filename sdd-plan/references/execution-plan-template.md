# 执行计划

任务拆分、任务设计和执行方式待人工确认；本文件不保存机器执行状态。

## 范围与交付

说明本计划覆盖的业务结果，以及与已确认需求和整体设计的关系。

## 执行方式与集成

说明串行/并行选择、依赖关系、真实输入和集成顺序；并行实现仍需用户明确确认。关键假设先最小验证，未满足的依赖不列为可立即并行；不按文件数拆任务。

## 整体验证方向

说明任务定向验证之外需要完成的集成验证及责任人；每个工作单元就近完成自己的测试与必要文档，不集中拖到最后。证据失效或不足时才补跑重叠验证，不伪造执行结果。

## 人工确认

待用户确认执行计划；不自动启动实现、Worker 或 worktree。
